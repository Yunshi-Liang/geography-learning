# 经纬 · 地理科学导论

一个以「地理科学导论」为体系的移动端学习 Web App，覆盖 **141 个知识点**，按大学地理科学课程体系编排，并通过**艾宾浩斯间隔复习**帮你把知识真正记住。可安装到手机主屏 / 桌面，离线也能用。

> 在线地址：https://yunshi-liang.github.io/geography-learning/

---

## ✨ 核心特性

- **科学学习路径**：将 141 个知识点按学科逻辑拆成 7 个阶段，先修关系清晰、难度递进——
  1. 地球与宇宙 → 2. 大气与气候 → 3. 海洋与水文 → 4. 岩石圈与地貌 → 5. 土壤与生物地理 → 6. GIS 与制图 → 7. 区域与人文
- **每日推荐 + 自动排程**：每天自动推荐「下一个待学点」；学完后按艾宾浩斯遗忘曲线 `[1, 2, 4, 7, 15, 30]` 天自动排复习，并移入复习区。
- **间隔复习测验**：复习环节用选择 / 判断 / 填空客观题即时反馈，巩固记忆。
- **完整学习进度表**：141 行进度表，含名称 / 状态（待学·复习中·已掌握）/ 上次学习 / 下次复习 / 复习次数，支持状态筛选。
- **阶段导览**：点击进度页的阶段条，展开查看每阶段的知识点与掌握情况。
- **数据备份**：学习进度可一键导出 / 导入 JSON，换设备不丢失。
- **PWA 可安装**：添加到主屏后全屏运行，类原生 App 体验；Service Worker 提供离线缓存。

---

## 📚 知识库结构

每个知识点按「**原理 → 过程（因果链）→ 现象 → 实例 → 生活关联**」的因果层次组织，而非孤立名词罗列。

| 领域 | 内容示例 |
| --- | --- |
| 地球与宇宙 | 自转公转、四季五带、月相、日月食、黄赤交角、圈层结构、天体观测、历法时间 |
| 大气与气候 | 辐射平衡、气压风带、局地环流、云降水、天气系统、气候类型、季风 / 洋流 / ENSO |
| 海洋与水文 | 海水性质、洋流、河流、湖泊湿地、地下水、冰川、水循环 |
| 岩石圈与地貌 | 风化、地质作用、板块、19 类地形地貌成因 |
| 土壤与生物地理 | 土壤形成与地带性、植被地带性、生物群落、生态系统 |
| GIS 与制图 | 投影、坐标系（CGCS2000 / WGS84）、栅格矢量、空间分析 |
| 区域与人文 | 人口、城市、农业、工业、文化地理 |

## 🚀 本地运行

纯静态、零依赖，任意静态服务器即可：

```bash
# 项目根目录
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

手机同 Wi‑Fi：访问 `http://<你的局域网IP>:8000/index.html`。

---

## 📲 安装到手机 / 桌面（PWA）

- **iOS Safari**：分享 →「添加到主屏幕」，即可作为 App 图标常驻主屏。
- **Android Chrome**：菜单 →「安装应用 / Add to Home screen」。
- **桌面（Chrome / Edge）**：地址栏右侧「安装」图标，或菜单 →「应用 → 安装此站点」。
- 安装后全屏运行，断网也能打开已缓存的页面。

## 🔧 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建步骤、无外部依赖，可直接双击 `index.html` 预览（部分浏览器需经 http 服务以启用 Service Worker）。
- 学习进度保存在浏览器 `localStorage`（键 `geo_spaced_v1`），不上传服务器。
- 部署通过 GitHub REST Contents API 上传至 `main` 分支并启用 GitHub Pages。
